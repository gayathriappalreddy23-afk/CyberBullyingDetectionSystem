Frequently Asked Questions

Quick answers to the most common questions we receive.

The system uses a trained Machine Learning / NLP model to analyse submitted text. It assigns a statistical likelihood score indicating whether the text contains patterns commonly associated with harmful or cyberbullying content. The model is based on supervised learning and does not make absolute determinations — human moderation is always recommended for borderline cases.

Submitted text is processed for analysis purposes and may be logged for system improvement and audit. It is not shared with third parties. For specific data handling or deletion requests, please contact us via the form above and select "Privacy / Data Request" as the category.

Yes — user registration is required to access the detection and analysis features. This ensures accountability and allows you to view your past analysis history. Registration is free and takes less than a minute.

Model accuracy depends on the dataset, language, and type of content. The system is designed as an assistive tool — not a final arbiter. We recommend using its results alongside human review, especially for moderation decisions. Accuracy metrics and model details are described on the About page.
